# Roadmap — build the full work, not a throwaway demo

## Foundation (current)
- product language and visual system
- BaZi calculation adapter
- prior → calibration → trajectory UI
- research falsification contract
- prediction-ledger schema
- data-source manifest and license boundaries

## Data construction
- versioned BaZi feature spec
- Wikidata canonical person table
- biography event ontology + extraction pipeline
- Pantheon/BHHT cohort adapter
- reliable birth-time research cohort
- deduplication / source reliability / date precision

## Research benchmark
- reality-only baseline
- BaZi-only baseline
- mixed model
- shuffled-birthday placebo distribution
- era holdout / geography holdout / missing-time experiments
- published model card with negative results included

## Lifetime engine
- archetype classifier
- age-window competing-risk models
- trajectory sequence model
- historical-neighbor retrieval
- uncertainty calibration
- branch simulator with user-controlled hinge variables

- “已然篇 / 校准篇 / 未然篇” full Fate Scroll
- provenance on every major claim
- model confidence and evidence drawer
- immutable prediction ledger and future scorecard

## Publication
- methodology page
- open benchmark + reproducible experiments where licensing permits
- technical essay: “Can fate-reading survive a validation set?”
- public leaderboard of model versions vs reality baselines and shuffled birthdays
