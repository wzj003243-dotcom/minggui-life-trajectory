# Timed birth snapshot v0.1

This is the first frozen, reproducible four-pillar research cohort for MingGui.

- Source: Astro-Databank official free C sample
- Input: **6,036** public records
- Primary timed cohort: **5,214** safely parsed AA/A/B records
- Rodden ratings: **AA 3,821 · A 1,161 · B 232**
- Calendar: **5,138 Gregorian · 76 Julian**
- All 76 Julian dates are converted to the Gregorian date representing the same physical day before feature generation.
- Feature schema: **bazi-objective-v0.1**
- Output feature width: **91 columns**
- User-facing deterministic “good/bad fate” labels are not part of this dataset.

The raw licensed/restricted data is not committed. This manifest records the source checksum and derived-artifact hashes so experiments can identify the exact snapshot used.
